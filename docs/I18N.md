# Internationalization (Languages)

The dashboard supports English (default) and Simplified Chinese display. The translation layer is fully frontend — no Python pipeline change, no backend, no runtime translation service. All copy is statically bundled.

## Using the toggle

| Surface | Behavior |
| --- | --- |
| `EN \| 中` pill in the persistent regime header | Click either side to switch immediately. The active side is highlighted; clicking it again is a no-op. |
| Keyboard | Press `g` then `i` to toggle. (`g l` is reserved for `/long-term`.) |
| URL | `?lang=en` or `?lang=zh` selects the locale and is shareable. The query string survives reload. |
| `localStorage` | Once selected, the locale persists across visits in `mwm.locale`. Same-origin tabs sync via the `storage` event. |
| `<html lang>` attribute | Updated to `en` or `zh-CN` so screen readers, CJK font fallback, and downstream styling behave correctly. |

Precedence (highest first): URL query parameter → `localStorage` → default English. The browser's `navigator.language` is **not** auto-detected. The dashboard's authoring voice is English; surprise switching is bad UX for a data dashboard.

## What gets translated

**UI chrome**
- Masthead, eyebrow, navigation, More menu, Brief/Detail mode toggle, keyboard-shortcuts dialog, `As of` date prefix, loading and error fallbacks.

**Persistent regime header**
- Regime label (`Risk-On`, `Risk-Off`, `Neutral`, `Stress`, plus compound forms like `Tightening / risk-off → 紧缩 / 避险`).
- Fragility label and value-pill, language toggle, mode toggle, shortcuts button.

**Cockpit cells (the ranked composite + vital-sign cards)**
- Cell labels render as `中文 (Original)` via the curated `SIGNAL_NAMES` table — for example, `波动率指数 (VIX)`, `10年期实际收益率 (10Y Real Yield)`, `高收益债期权调整价差 (HY OAS)`.
- Categorical readings: `stretched | neutral | tight | wide | rich | cheap | rising | falling | flat | normal` → `拉伸高位 | 中性 | 偏紧 | 走阔 | 估值偏高 | 估值偏低 | 上升 | 下降 | 持平 | 正常`.

**Driver bars (`TOP ACTIVE WARNINGS` / `SUPPORTS`)**
- Driver card titles via `DRIVER_TITLE_TRANSLATIONS` (24 entries): `通胀压力`, `净流动性`, `信用利差`, `就业周期`, `广义美元`, `增长广度`, `消费者资产负债表`, etc.
- Horizon chips: `BOTH → 两者`, `SHORT-TERM → 短期`, `LONG-TERM → 长期`, `FRAGILITY → 脆弱度`.
- Numeric labels: `Importance → 重要性`, `Severity → 严重程度`, `Confidence → 置信度`.
- Driver detail and why-it-matters prose: roughly 83% match a translation template and render in Chinese; the remaining 17% (gated/candidate signals with multi-clause copy) wrap in `<span lang="en">`.

**Sub-component breakouts** (Net Liquidity card)
- `Fed assets / Treasury General Account / Reverse repo` → `联储资产 / 财政部一般账户 / 逆回购`.

**FocusBlock (the routeInsight section panels)**
- Eyebrow + question (static fields from `SECTION_CATALOG`) translate via `focus.<sectionId>` keys.
- `answer`, `why`, `risk`, `support`, `caveat` (dynamic Python f-strings with numeric interpolation) stay English under Chinese; wrapped in `<span lang="en">`. Translating these properly requires a Python pipeline change to emit a stable `template_variant` key and `vars` payload — deferred.

**Glossary tooltips (`<abbr title>`)**
- Each entry has both `en` and `zh` definitions. Under Chinese, the tooltip flips while the visible (canonical English) key stays. Lookup is case-sensitive on the canonical English label.

**Routes**
- Each route translates its top-level heading, intro subtitle paragraph, and section headings. Long-form prose in `Methodology.tsx` is translated. Long-form copy embedded in panels (e.g. `BondVolatilityProxyChart` description, `HiddenStressMismatchPanel`) is translated where it lives in TSX.

**Tables and pills**
- Diff: cadence pills (`1日 / 1周 / 1月`, `日频 / 周频 / 月频`), composite + vital-sign row labels (via the same `SIGNAL_NAMES` lookup), empty-state copy.
- Calendar: column headers (`日期 / 时间 / 事件 / 重要性`), impact labels.
- DataGapPanel: table headers (`序列 / 状态 / 观测 / 备注`), status pills (`正常 / 过时 / 待条款审核 / 不可用`).
- FreshnessPill: `新鲜 / 过时 / 未知 / 缺失`.
- DataQualityBanner: tier word renders as `数据质量评级: 高 / 中 / 低 / 稀疏` under Chinese (cleaner word order than the previous `高 数据质量`).

## What stays English by design

- Numeric values, dates, percentages, basis-point counts.
- Tickers and series IDs: VIX, MOVE, SKEW, DGS10, DCOILWTICO, WALCL, etc.
- Provider names: Cboe, ICE, NY Fed, BLS, FRED, Treasury.gov, Cleveland Fed, BEA.
- URLs, external link text, source-attribution captions.
- FocusBlock `answer / why / risk / support / caveat` paragraphs (Python f-strings with numeric interpolation).
- ~17% of driver-detail / why-it-matters paragraphs that don't match a translation template (typically gated/candidate signals with complex multi-clause prose).
- DataGapPanel observation and note columns (Python-generated freshness explanations with embedded dates from `data_status.json`).

Fall-through English text wraps in `<span lang="en">` so screen readers handle it correctly and CJK font fallback does not pick it up.

## Architecture

```
src/lib/i18n/
  locale.tsx     # LocaleProvider, useLocale, setLocale, resolveLocale
  en.ts          # English dictionary (source of truth for the key shape)
  zh.ts          # Simplified Chinese dictionary (typed as En)
  signals.ts     # SIGNAL_NAMES (curated indices), COCKPIT_ID_TO_SIGNAL_KEY
  drivers.ts     # DRIVER_TITLE_TRANSLATIONS, tDriver()
  narrative.ts   # NARRATIVE_OVERRIDES, regex templates, tNarrative()
  t.ts           # useT() hook returning { t, tCategorical, tDriver, tNarrative, locale }
  index.ts       # barrel re-export
  __tests__/     # vitest specs for precedence, fallback, parenthetical, templates
```

The `LocaleProvider` mirrors `ModeProvider` in `src/lib/mode.tsx`. The `useT()` hook reads the active locale from React context and returns translation helpers; falling back to English when a Chinese key is missing.

## How to add a translation

### A new static string

1. Add the English value at the appropriate path in `en.ts`.
2. Add the matching key/value in `zh.ts`. The `En` type catches missing keys at compile time.
3. At the render site:
   ```tsx
   import { useT } from "../lib/i18n";
   const { t } = useT();
   return <span>{t("nav.overview")}</span>;
   ```

### A new curated index or jargon label

1. Add an entry to `SIGNAL_NAMES` in `signals.ts`:
   ```ts
   coreCpiYoY: { zh: "核心 CPI 同比", original: "Core CPI YoY" },
   ```
2. If the cockpit ID differs from the signal key (snake_case vs. camelCase), add a `COCKPIT_ID_TO_SIGNAL_KEY` entry.
3. At the render site:
   ```tsx
   const label = t("signals.coreCpiYoY", { withOriginal: true });
   // English: "Core CPI YoY"
   // Chinese: "核心 CPI 同比 (Core CPI YoY)"
   ```

### A new Python-emitted driver title

1. Add an entry to `DRIVER_TITLE_TRANSLATIONS` in `drivers.ts`:
   ```ts
   "Housing affordability": "住房可负担性",
   ```
2. At the render site, call `tDriver(driver.title)`. Returns the English title unchanged when no match is found.

### A new driver-narrative template

The narrative matcher tries exact matches in `NARRATIVE_OVERRIDES` first, then regex templates. To add a template:

1. Add a regex + Chinese template to `narrative.ts`. Use `$1`, `$2` for captured subject phrases. Single-noun captures can route through `SUBJECT_TRANSLATIONS` for finer-grained translation.
2. Add a unit test exercising the new template.
3. Verify by browsing `?lang=zh` and confirming the paragraph translates instead of falling back to the `<span lang="en">` wrapper.

Best-effort guidance: 10–15 templates covering common phrasings is sufficient. Don't pursue 100% coverage manually — that path requires a Python pipeline change to emit structured variables.

### A new categorical label (regime, reading, status, horizon, freshness)

1. Extend the `categoricals` block in `en.ts` + `zh.ts`.
2. At the render site, call `tCategorical("group", value)`. Falls back to the original English string if no match.

## Translation accuracy guidelines

The dashboard uses **Mainland financial-press conventions** (财新, 第一财经, CICC research, MBA智库). Avoid Hong Kong or Taiwanese variants. Specific terminology choices:

| English term | Chinese | Reason |
| --- | --- | --- |
| Option-adjusted spread (OAS) | 期权调整价差 | 价差 is the standard noun form; 利差 = yield spread (less precise) |
| Macro Climate | 宏观环境 | 气候 is too literal (= weather); 宏观环境 is idiomatic |
| Severity | 严重程度 | Standard noun form; 严重度 is less common in formal writing |
| Confidence | 置信度 | Financial-press standard for statistical/quality confidence |
| Stale (data freshness) | 过时 | More natural than 陈旧 (= "obsolete/old") in a data-quality context |
| Term premium | 期限溢价 | CICC research convention |
| Net liquidity | 净流动性 | Standard; formula: `美联储资产 - TGA - 隔夜逆回购` |
| Treasury General Account (TGA) | 财政部一般账户 | Standard |
| Reverse repo / ON RRP | 逆回购 / 隔夜逆回购 | Standard |
| Risk-On / Risk-Off | 风险偏好 / 避险 | 避险 chosen over 风险规避 for compact UI cells; both are widely used |
| Stretched (valuation/positioning) | 拉伸高位 | Distinct from 偏紧 (tight) to avoid collision |
| Reallocation / rotation | 再平衡 / 板块轮动 | 再平衡 = rebalancing; 板块轮动 = sector rotation |

When in doubt, prefer the standard Mainland press term. If a translation is ambiguous, leave a comment in `zh.ts` explaining the choice.

## Adding a third language

The dictionary shape and `useT()` API support additional locales with localized changes:

1. Create a new dictionary file (for example, `src/lib/i18n/jp.ts`) typed as `En`.
2. Add the locale code to `Locale` in `locale.tsx` and update `VALID_LOCALES`.
3. Update `LanguageToggle` to render a wider selector (currently hardcoded to two options).
4. Add any locale-specific font fallback in `src/styles.css` if needed.
5. Translate or extend `SIGNAL_NAMES`, `DRIVER_TITLE_TRANSLATIONS`, `NARRATIVE_OVERRIDES`, and the `categoricals` blocks. The English fallback in `useT()` continues to work for partial translations.

## Testing

- **Unit tests** (`src/lib/i18n/__tests__/`) cover locale precedence, `useT()` lookup, parenthetical rendering, missing-key fallback, `tDriver()` and `tNarrative()` template matching.
- **Component tests** mount under `<LocaleProvider initialLocale="en">` and assert on English text. To test Chinese behavior, wrap in `<LocaleProvider initialLocale="zh">`.
- **Visual smoke** uses `agent-browser` at 1440x900 (desktop) and 375x812 (mobile) to verify that Chinese strings don't overflow or wrap awkwardly on key routes (`/`, `/short-term`, `/long-term`, `/fragility`, `/diff`, `/methodology`).
- **Regression discipline**: when refactoring a component that currently uses `useT()`, do not strip `lang="en"` wrappers from fall-through narrative paragraphs.
